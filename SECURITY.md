# Security

Please report security problems privately, through
[Report a vulnerability](https://github.com/ljxw88/omarchy-phonelink/security/advisories/new)
on GitHub, not in a public issue.

Say what an attacker could do, and how to reproduce it. This is a volunteer
project: expect a first reply within a week.

Problems in scrcpy or adb themselves belong upstream:
[scrcpy](https://github.com/Genymobile/scrcpy) and
[Android](https://source.android.com/docs/security/overview/updates-resources#report-issues).

phonelink only supports the latest version on `master`.
